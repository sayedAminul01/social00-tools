    What Is This Merge PDF Tool?

    This tool combines two or more PDF files into a single PDF, in an order you control — all without installing anything or sending your documents anywhere. It uses PDF.js to read and preview each file and pdf-lib to build the merged output, both running entirely on your own device.

    Why Merge PDFs Into One File?

    Sending or storing a stack of separate PDFs is easy to lose track of and awkward to review. Merging them into one file makes it simple to share a full report, combine scanned pages with a cover letter, or assemble a set of invoices, contracts, or chapters into a single document that opens and prints in the right order.

    How the Merge Works

    Each PDF you add is parsed locally to read its page count and render a first-page thumbnail. When you click Merge, pdf-lib loads every file's original bytes and copies its pages directly into one new document, in the exact order shown in your list — page content, fonts, and images are copied as-is, not re-rendered or recompressed.

    Reordering Before You Merge

    Every file in the list has up and down buttons so you can arrange them into the order you want pages to appear in the final PDF, plus a remove button to drop a file entirely. You can add more files at any point before merging, and the running total updates as you go.

    A Real Limitation: Encrypted PDFs

    pdf-lib, the library this tool uses to build the merged file, cannot open password-protected or encrypted PDFs. If one of your files is locked, remove the password with a PDF reader first — this tool will flag any file it can't parse rather than failing silently.

    Benefits of Using This Tool

    • 100% private — your files never leave your device

    • Free, unlimited, no sign-up, no watermark

    Frequently Asked Questions

    Is my PDF uploaded to a server?

    No. This tool reads your files locally using PDF.js and pdf-lib, both running entirely in your browser. Your PDFs are never uploaded anywhere — the merge happens on your own device.

    Can I change the order of the files before merging?

    Yes. Every file you add appears in a list with up and down buttons, so you can arrange them into the exact order you want the pages to appear in the final PDF.

    Can I merge password-protected PDFs?

    No. This tool relies on pdf-lib, which cannot open encrypted or password-protected PDFs. You'll need to remove the password first using a PDF reader before merging.

    Is there a limit on how many PDFs I can merge?

    No fixed limit is imposed by this tool. Since everything runs in your browser, the practical limit depends on your device's memory and how large your combined files are.

    Will merging affect the quality or content of my PDFs?

    No. Each page is copied directly from the source file into the new document, preserving the original text, images, fonts and quality exactly — nothing is re-rendered or recompressed.

    Is this tool free?

    Yes — completely free, no account required, no watermark, and no limit on file count imposed by this tool. Everything runs locally in your browser.
