What Is This Split PDF Tool?

This tool lets you pull specific pages out of a PDF, or break every page into its own file — without installing anything or sending your document anywhere. It uses PDF.js to render page thumbnails and pdf-lib to build the output files, both running entirely on your own device.

Extract Selected Pages vs. Split Into Separate Files

Extract Selected Pages builds one new PDF containing only the pages you've checked, always in their original ascending order — useful for pulling a chapter or a signed section out of a larger document. Split Into Separate Files creates one single-page PDF per checked page (or every page, if you haven't checked any) and bundles them into a single downloadable ZIP.

Selecting Pages: Checkboxes or a Range

Click checkboxes directly on the page thumbnails, or type a range like 1-3,5,8-9 into the page range field — the two stay in sync in both directions. Typing a valid range checks the matching thumbnails, and checking or unchecking a thumbnail updates the text field to match what's actually selected.

How Splitting Works

Every output file is built the same way: pdf-lib copies the requested page(s) directly from your original file's bytes into a brand-new document, preserving the original content, fonts and images exactly — nothing is re-rendered or recompressed. For the ZIP output, each single-page PDF is added to an in-browser ZIP archive using JSZip before download.

A Real Limitation: Encrypted PDFs

pdf-lib and PDF.js, the libraries this tool relies on, cannot open password-protected or encrypted PDFs. If your file is locked, remove the password first with a PDF reader — this tool will show a clear message if a file can't be opened rather than failing silently.

Frequently Asked Questions

Is my PDF uploaded to a server?

No. This tool reads your file locally using PDF.js and pdf-lib, both running entirely in your browser. Your PDF is never uploaded anywhere — splitting happens on your own device.

What's the difference between the two modes?

"Extract Selected Pages" builds one new PDF containing only the pages you checked, in their original order. "Split Into Separate Files" creates one single-page PDF per checked page (or every page if none are checked) and bundles them into a downloadable ZIP.

Can I type a page range instead of clicking checkboxes?

Yes. Type a range like "1-3,5,8-9" into the page range field and the matching checkboxes are ticked automatically. It also works the other way — checking or unchecking a box updates the text field to match.

Does the page order in the output follow the order I clicked?

No — the extracted PDF always keeps pages in their original ascending order from the source file, regardless of the order you checked them in.

Can I split a password-protected PDF?

No. This tool relies on pdf-lib and PDF.js, which cannot open encrypted or password-protected PDFs. You'll need to remove the password first using a PDF reader before splitting.

Is this tool free?

Yes — completely free, no account required, no watermark, and no page-count limit imposed by this tool. Everything runs locally in your browser.
