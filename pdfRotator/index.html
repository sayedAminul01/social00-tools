    What This Tool Does

    Rotate PDF fixes pages that were scanned or saved sideways or upside-down. Upload a PDF, spin any page 90° at a time with its own thumbnail controls, and download a corrected copy — all without installing software or sending your file anywhere.

    Rotate One Page or All of Them

    Each page thumbnail has its own rotate-left (⟲) and rotate-right (⟳) buttons, so you can fix only the pages that need it. If an entire scan came in sideways, the Rotate All 90° button turns every page at once — and both approaches can be combined and stack cumulatively.

    How Rotation Is Applied

    Nothing touches your file while you work — every click just queues a rotation in memory. When you download, this tool uses pdf-lib to load a fresh copy of your original PDF and set each page's rotation, adding your queued turn on top of any rotation the page already had, so pages that were already rotated in the source file end up correct too.

    No Quality Loss

    Rotating a PDF page only changes its orientation flag in the file — the text, images, and vector graphics on the page are never re-drawn, flattened, or re-compressed. Your output keeps the same text layer, sharpness, and searchability as the original.

    Frequently Asked Questions

    Is my PDF uploaded to a server?

    No. This tool reads your PDF locally using PDF.js for previews and pdf-lib for the export, both running entirely in your browser. Your file is never uploaded anywhere — everything happens on your own device.

    Can I rotate just one page instead of the whole document?

    Yes. Every page has its own rotate-left and rotate-right buttons, so you can spin only the pages that are sideways or upside-down and leave the rest untouched.

    What does "Rotate All 90°" do if I already rotated some pages individually?

    It adds another 90° turn on top of whatever each page is already queued at, rather than resetting anything. A page you already rotated to 180° becomes 270° after Rotate All, while an untouched page simply becomes 90°.

    Will rotating pages reduce quality or change the file size much?

    No. Rotation only changes a page's orientation flag — the underlying text, images, and vector content are copied through untouched, so there's no re-encoding or quality loss and file size stays essentially the same.

    Why won't my PDF open in this tool?

    The file may be corrupted or, more commonly, password-protected. Both PDF.js and pdf-lib, the libraries this tool runs on, cannot open encrypted PDFs — you'd need to remove the password with the file's original owner or software first.

    Is this tool free?

    Yes — completely free, no account required, no watermark, and no limit on file size or how many times you use it. Everything runs locally in your browser.
