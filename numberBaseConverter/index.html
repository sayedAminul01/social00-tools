What Is a Number Base?

A number base (or radix) defines how many unique digits a counting system uses before it rolls over into a new place value. Decimal, the system most people count in, uses 10 digits (0-9). Binary uses only 2 (0-1), octal uses 8 (0-7), and hexadecimal uses 16 — the ten decimal digits plus a-f standing in for 10 through 15. The same quantity can be written in any of these systems; only the representation changes.

How Positional Notation Works

Every digit in a number carries a value equal to itself multiplied by the base raised to its position, counted from 0 at the rightmost digit. Take binary 1101: reading right to left, that's (1×2⁰) + (0×2¹) + (1×2²) + (1×2³) = 1 + 0 + 4 + 8 = 13 in decimal. The exact same mechanism converts hex 1a to decimal: (a×16⁰) + (1×16¹) = 10 + 16 = 26. Only the base value in the exponent changes.

Binary in Low-Level Computing

Transistors are either on or off, so hardware naturally speaks in two states: 0 and 1. Every CPU instruction, memory cell, and network packet ultimately reduces to binary digits, and bitwise operations — AND, OR, XOR, shifts — operate directly on those bits. Programmers work with binary explicitly when writing flags, masks, and low-level protocol handling.

Octal and Unix File Permissions

Unix-style permissions group access rights into three 3-bit sets — owner, group, and other — and 3 bits map perfectly onto a single octal digit (0-7). Running chmod 755 sets binary 111 101 101: full read/write/execute for the owner, and read/execute for group and everyone else. Octal survives in permission syntax purely because it condenses those bit groups so cleanly.

Hexadecimal for Bytes, Addresses & Colors

One hex digit represents exactly 4 bits, so two hex digits represent a full byte (0-255) — far more compact than writing out 8 binary digits. That's why memory addresses, debugger byte dumps, and RGB color codes like #ff8800 are written in hex: it's a dense, human-readable stand-in for the raw binary underneath.

Frequently Asked Questions

What is a number base (radix)?

A number base, or radix, is how many distinct digits a numbering system uses before it carries over into a new place value. Binary uses 2 digits (0-1), octal uses 8 (0-7), decimal uses 10 (0-9), and hexadecimal uses 16 (0-9 and a-f).

How does positional notation work across bases?

Each digit's value is multiplied by the base raised to its position, counting from 0 on the right. For example, binary 1101 = (1×2³) + (1×2²) + (0×2¹) + (1×2⁰) = 8 + 4 + 0 + 1 = 13 in decimal. The same logic applies to any base, just swap in that base's value for the exponent.

Why is binary used in computing?

Computer hardware is built from transistors that are either on or off, which maps naturally to two states: 0 and 1. Every operation a CPU performs, from arithmetic to bitwise logic (AND, OR, XOR, shifts), happens directly on these binary values.

Why do Unix file permissions use octal, like chmod 755?

Unix permissions pack three 3-bit groups (owner, group, other), and 3 bits map exactly to one octal digit (0-7). "755" is really binary 111 101 101 — read, write, execute for the owner, and read, execute for group and other — condensed into three easy-to-type digits.

Why is hexadecimal used for memory addresses and colors?

One hex digit represents exactly 4 bits (half a byte), so two hex digits cleanly represent a full byte (0-255). This makes hex a compact, human-readable stand-in for raw binary data, which is why it's used for memory addresses, byte dumps, and RGB colors like #ff8800.
