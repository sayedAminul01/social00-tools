What Is a Text Case Converter?

A text case converter rewrites the same text into a different capitalization style — UPPERCASE, lowercase, Title Case and more — without changing the words themselves. It's a quick fix for text pasted from a form that autocapitalized everything, a heading that needs proper Title Case, or a variable name that needs reshaping for code.

Programming Naming Conventions

camelCase (firstName) is standard for variables and functions in JavaScript, Java and Swift. PascalCase (UserProfile) names classes and components. snake_case (user_name) is common in Python, Ruby and database columns. CONSTANT_CASE (MAX_RETRIES) marks constants and environment variables. kebab-case (user-name) is the norm for URLs, CSS classes and file names.

The Real Title Case Rule

Proper Title Case isn't "capitalize every word" — most style guides lowercase short conjunctions, articles and prepositions (a, an, the, and, but, or, for, of, on, to, as, if, and similar) unless one of them opens or closes the sentence. This tool applies that exact rule, so "a Tale of Two Cities" style words stay lowercase in the middle of a title.

Sentence Case for Body Text

Sentence case lowercases everything and capitalizes only the first letter of each sentence — the way normal prose is written. It's the right choice for body copy, captions and descriptions where Title Case would look overcapitalized and shouty.

aLtErNaTiNg and InVeRsE Case

aLtErNaTiNg case flips between lowercase and uppercase letter by letter — a playful style popular in memes and sarcastic quote formatting. InVeRsE case (also called Sponge Case) simply flips the existing case of every letter, turning "Hello World" into "hELLO wORLD".

Everything Runs Locally

Frequently Asked Questions

What is the rule for Title Case?

Capitalize the first letter of every major word, but lowercase common short conjunctions, articles and prepositions (a, an, the, and, but, or, nor, for, so, yet, at, by, in, of, on, to, up, as, if) unless one of them is the very first or very last word of the text, in which case it's always capitalized too.

What's the difference between camelCase and PascalCase?

Both remove spaces and capitalize the start of each word. camelCase starts with a lowercase letter (myVariableName); PascalCase capitalizes the very first letter too (MyClassName).

When should I use snake_case vs kebab-case?

snake_case (words_like_this) is common for variable and file names in Python, Ruby and SQL. kebab-case (words-like-this) is common in URLs, CSS class names and command-line flags, since underscores aren't always URL- or CLI-friendly.

What is CONSTANT_CASE used for?

CONSTANT_CASE (also called SCREAMING_SNAKE_CASE) is the near-universal convention for naming constants and environment variables across languages, e.g. MAX_RETRY_COUNT or API_BASE_URL.

How does Sentence case handle multiple sentences?

It lowercases the whole text, then capitalizes the very first letter and the first letter after every '. ', '! ' or '? ' — so each new sentence starts with a capital letter, matching normal prose rules.

Does this tool send my text anywhere?

No. Every conversion runs locally in your browser with plain JavaScript. Your text is never uploaded, logged or sent to a server.
