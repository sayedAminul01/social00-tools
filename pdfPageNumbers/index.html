What This Tool Does

This tool stamps a page number onto every page of a PDF — choose where it sits, how it reads, and where the count starts, then download the finished file. It's built for the common case: a report, ebook, or contract that needs clean pagination without opening desktop software.

Position, Format & Starting Number

Pick any of the six corner/edge positions, choose a preset format or type your own using {n} and {total} as placeholders, and set a starting number other than 1 if this file continues from an earlier document. Font size and color are adjustable too.

Skipping a Cover Page

Check Skip first page and the first page gets no stamp at all — the page right after it becomes the one showing your chosen starting number, so a cover page never throws off the count.

What {total} Means

{total} always refers to the document's total physical page count, including any page you chose to skip. In a 10-page file with the cover skipped, the first numbered page reads "Page 1 of 10" — the total reflects the whole document, not just the pages that got a number.

Precise, Real PDF Text

Numbers are added using pdf-lib's native text drawing with the standard Helvetica font, with each position calculated from the exact page dimensions and measured text width — not a flattened image. The result stays sharp, searchable, and selectable at any zoom.

Privacy: Everything Happens in Your Browser

  • Your PDF is read locally and never uploaded to a server
  • Rendering (PDF.js) and export (pdf-lib) both run on your device

Frequently Asked Questions

Is my PDF uploaded to a server?

No. This tool reads your PDF locally using PDF.js for the preview and pdf-lib for the export, both running entirely in your browser. Your file is never uploaded anywhere — everything happens on your own device.

What does {total} mean if I skip the first page?

{total} always equals the document's total physical page count, including any skipped cover page. For example, in a 10-page document with the cover skipped, the second page (the first numbered one) reads "Page 1 of 10", not "Page 1 of 9" — the total reflects the whole file, not just the numbered pages.

How does "Skip first page" affect the numbering?

The first page gets no stamp at all, and the page right after it becomes the one showing your chosen starting number. So with a starting number of 1, physical page 2 shows "1", physical page 3 shows "2", and so on — the cover page is excluded from the count entirely rather than being page "0".

Can I start numbering from something other than 1?

Yes. Set any starting integer, which is useful when this file is a continuation of another document — for example starting at 45 so the numbering carries on from a previous part.

Will this replace page numbers my PDF already has?

No. This tool stamps new page numbers as a separate layer on top of the page — it can't detect or remove existing printed numbers. If your document already has numbers baked into the page content, you'll end up with both, so use this tool on documents that don't already have numbering.

Why won't my PDF open in this tool?

The file may be corrupted or, more commonly, password-protected. Both PDF.js and pdf-lib, the libraries this tool runs on, cannot open encrypted PDFs — you'd need to remove the password with the file's original owner or software first.
