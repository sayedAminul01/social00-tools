Hue, Saturation & Lightness Explained

Hue is the base color itself, measured as a position on a 0-360° color wheel — 0° is red, 120° is green, 240° is blue, and it wraps back to red at 360°. Saturation controls how intense that color is, from a flat grey at 0% to a fully vivid color at 100%. Lightness controls how close the color sits to black (0%) or white (100%), with 50% giving the purest, most saturated version of the hue.

The Harmony Types Explained

Complementary pairs a hue with its opposite (180° away) for maximum contrast. Analogous uses hues that sit close together on the wheel for a naturally harmonious feel. Triadic spaces three hues 120° apart for a vibrant but balanced look. Split-complementary softens a complementary pair by using the two hues next to the opposite color. Tetradic uses four hues in two complementary pairs for rich, varied palettes. Monochromatic keeps one hue and only varies the lightness, producing a cohesive, low-risk palette.

Choosing a Palette for Your Brand

For a brand or logo, cohesion usually beats novelty — monochromatic or analogous harmonies read as calm and professional because the colors already sit near each other on the wheel. Save complementary or triadic combinations for accents, calls-to-action, or projects where you want energy and contrast, and use a single dominant color with the rest as supporting shades rather than treating all five swatches as equals.

A Note on Accessibility

A visually harmonious palette isn't automatically a readable one. If you plan to pair any of these colors as text on a background, check the contrast ratio against the Web Content Accessibility Guidelines (WCAG) before shipping it — this tool generates color harmony, not contrast compliance, so run text/background pairs through a dedicated contrast checker first.

A Worked Example

Start with #2563EB, a strong blue. Converting to HSL gives roughly hsl(221°, 83%, 53%). Choosing Complementary shifts the hue by 180° to about 41° — a warm amber — and adds a lighter and darker shade of each for five usable swatches. Choosing Monochromatic instead keeps that same 221° hue and 83% saturation, and only steps the lightness through 20%, 35%, 50%, 65% and 80%.

Frequently Asked Questions

What's the difference between hue, saturation and lightness?

Hue is the base color on a 0-360° wheel (0 is red, 120 is green, 240 is blue). Saturation is how intense the color is, from grey to fully vivid. Lightness is how close it sits to black or white, with 50% being the purest version of the hue.

Which harmony type should I use for a logo or brand?

Monochromatic or analogous harmonies usually look cohesive and professional since the colors sit close together on the wheel. Complementary or triadic harmonies create more contrast and energy, good for bold accents but harder to balance across a full brand.

Can I generate a palette from a color name instead of a hex code?

Yes — type a word like "ocean" or "sunset" and the tool sums the character codes of the letters, maps that number to a hue with modulo 360, and pairs it with a fixed 65% saturation and 50% lightness. It's a deterministic hash, not a curated designer pick, but the same word always gives the same color family.

How do I use the CSS variables output?

"Copy as CSS Variables" copies a ready :root block with --color-1 through --color-5 set to your palette's hex codes. Paste it into your stylesheet and reference each color with var(--color-1), var(--color-2), and so on.

Is this tool free?

Yes — completely free, no account required, no limit on how many palettes you generate. Everything runs locally in your browser.

Does this check color accessibility or contrast?

Not currently. It generates harmonious palettes based on HSL color theory, but it doesn't calculate WCAG contrast ratios. If you're using a palette for text on a background, verify contrast separately with a dedicated contrast checker.
