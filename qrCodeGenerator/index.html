How a QR Code Is Built

A QR code is a grid of black and white squares called modules. Three large squares in the corners — the finder patterns — let a scanner detect the code's position and rotation instantly. A thin alternating line called the timing pattern tells the scanner exactly where each row and column of modules falls, and a blank margin called the quiet zone separates the code from everything else on the page so it doesn't blur into surrounding content.

Error Correction, Explained Simply

Every QR code stores extra, redundant data alongside the real message using a technique called Reed-Solomon error correction. That's what lets a code still scan after a corner is torn off or a logo is placed in the middle. There are four levels — L (~7%), M (~15%), Q (~25%) and H (~30%) recoverable data — and this tool always uses Level M, a reliable balance between correction strength and how much data fits in a given size.

The Wi-Fi QR Code Format

A Wi-Fi QR code is just a specially formatted piece of text: WIFI:T:WPA;S:NetworkName;P:Password;;. T is the security type (WPA, WEP, or nopass for open networks), S is the network name, and P is the password. When a phone camera scans it, it recognizes the format and offers to join the network directly — handy for guests instead of reading a password out loud.

Common Uses for QR Codes

Restaurant menus, Wi-Fi sharing at home or in an office, business cards and event badges, linking a printed flyer to a website, app store download links, and boarding passes or event tickets are some of the most common everyday uses — anywhere a printed surface needs to hand off to a phone instantly.

Frequently Asked Questions

Does this QR code generator send my data anywhere?

No. The QR encoder is written entirely in JavaScript and runs in your browser — your text, URL or Wi-Fi details are never sent to a server or a third-party QR-image API. Nothing you type here is ever uploaded.

What does "Error Correction Level M" mean?

QR codes store the same data twice using Reed-Solomon error correction so a scanner can still read the code even if part of it is dirty, torn or covered by a logo. Level M can recover roughly 15% of the code's data — a solid middle ground between raw storage capacity (Level L, ~7%) and heavy damage resistance (Level H, ~30%), which is why it's used as the default here.

How does the Wi-Fi QR code format work?

A Wi-Fi QR code encodes a plain-text string in the form WIFI:T:WPA;S:NetworkName;P:Password;; — T is the security type (WPA, WEP or nopass), S is the network name (SSID), and P is the password. Scanning it with a phone camera offers to join that network directly, without anyone having to type the password by hand.

Why does every QR code have a blank white border?

That border is called the quiet zone. Scanners use the sharp contrast between the code and empty space around it to detect where the QR code starts and stops, so the ISO/IEC 18004 standard requires a clear margin of at least 4 modules on every side. Removing it can stop the code from scanning at all.

How much text can a QR code actually hold?

It depends on the QR version (its size, from 21×21 up to 177×177 modules). At Error Correction Level M in byte mode, version 1 holds about 14 bytes and the largest version, 40, holds about 2,331 bytes. This tool automatically picks the smallest version that fits whatever you type.

Can I use custom colors and will the QR code still scan?

Yes, but keep strong contrast between the foreground and background colors. Scanners rely on clearly distinguishing dark modules from light ones, so two similar colors (like light grey on white) can make a code unreliable or unscannable even though it still looks correct on screen. This tool warns you when your chosen colors are too close.

Yes — completely free, no account required, no limit on how many QR codes you generate. Everything runs locally in your browser.
