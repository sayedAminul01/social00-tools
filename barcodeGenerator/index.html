How Code 128 Barcodes Work

A Code 128 barcode is a sequence of black bars and white spaces of varying width, grouped into modules — the narrowest unit of width the barcode uses. Every character you type maps to one of 103 possible symbol values, and each symbol value has an exact, standardized 11-module bar/space pattern. Unlike a QR code, there's no error-correction grid or masking pattern to compute — Code 128 is deterministic, but the pattern table and checksum still have to be exactly right for a scanner to read it.

Why Code Set B

Code 128 actually defines three character sets — A, B and C — and a full encoder can switch between them mid-barcode to pack digits more densely. This tool implements Code Set B on its own, which covers the entire printable ASCII range (32-126): every uppercase and lowercase letter, digit, space and common punctuation mark. That makes it the most versatile of the three for general alphanumeric barcodes, without any of the complexity of set-switching.

The Checksum That Catches Misreads

Right before the stop pattern, every Code 128 barcode carries a checksum symbol computed from a weighted sum: the Start Code's value, plus each data character's symbol value multiplied by its position (1st, 2nd, 3rd...), all summed and taken modulo 103. A scanner recomputes this same sum from what it read and compares it — if a smudge or a bad angle changes even one bar, the checksum won't match and the scan is rejected instead of silently returning wrong data.

Real-World Uses — and What This Isn't For

Code 128 is everywhere in shipping and logistics — package labels, pallet tags, inventory and warehouse tracking, ID badges, and internal asset tags all lean on its density and alphanumeric flexibility. It's worth being upfront about scope, though: the barcode on a can of soup at a retail checkout is UPC-A or EAN-13, a different, numeric-only symbology with its own fixed structure. This tool generates Code 128, not retail product barcodes.

Frequently Asked Questions

What is Code 128?

Code 128 is a high-density 1D barcode symbology that encodes text using variable-width bars and spaces. Each character maps to an exact 11-module bar pattern from a fixed lookup table, and a checksum symbol protects the whole barcode from being misread.

Why does this tool use Code Set B specifically?

Code 128 has three character sets — A, B and C — and a full implementation can switch between them mid-barcode. Code Set B covers the entire printable ASCII range (32-126), which is every letter, digit and common punctuation mark, making it the most versatile choice for general text and alphanumeric barcodes without needing any set-switching.

Can I use this for retail product barcodes like UPC or EAN?

No — retail product barcodes use UPC-A or EAN-13, a different, numeric-only symbology with its own fixed structure. This tool generates Code 128 barcodes, which are widely used for shipping labels, inventory and internal tracking, but they won't scan as a UPC/EAN product code at a retail checkout.

What characters can I encode?

Code Set B supports the full printable ASCII range: letters (A-Z, a-z), digits (0-9), space, and standard punctuation and symbols from ! through ~. Characters outside that range, such as emoji or most non-Latin scripts, aren't supported and will be rejected with a warning instead of producing a broken barcode.

Does this barcode generator upload my data anywhere?

No. The Code 128 encoder runs entirely in JavaScript in your browser — your text is never sent to a server. Nothing you type here is ever uploaded.

Is this tool free?

Yes — completely free, no account required, no limit on how many barcodes you generate. Everything runs locally in your browser.
